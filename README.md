# CAPA_Effectiveness_Prediction
This project uses Machine Learning to predict whether a manufacturing, medical, or engineering fix-it plan (CAPA) will succeed before a company spends time and money executing it.
Traditionally, companies write a Corrective and Preventive Action (CAPA) plan, execute it, and hope it works. If it was a bad plan, the same mistake happens again a few months later, causing lost time and money. This project replaces that reactive process with a proactive Early Stage Quality Intelligence Engine.
The moment a manager types a new draft into the interactive dashboard, the AI benchmarks the profile and text against historical data to analyze risks instantly.

🔮 What the AI Predicts

• Will it work? — 🟢 Effective vs 🔴 Ineffective (High Rework Risk) with a specific confidence score.
• Will the mistake happen again? — ⚠️ High Risk vs ✅ Low Risk of the problem returning within 90 days.
• How long will it take? — A precise Forecasted Cycle Time predicting the exact number of days to complete and close the plan.
