# CAPA_Effectiveness_Prediction

In factories, medical companies, and engineering plants, deviations occur. When a deviation occurs, teams write a fix-it plan called a CAPA (Corrective and Preventive Action).
Traditionally, companies write a CAPA execute it, and just hope it works. If it was a bad plan, the same mistake happens again a few months later, causing lost time and money.
This project changes that. It uses Artificial Intelligence (Machine Learning) to act like a smart assistant. The moment a manager types up a new plan, the AI checks it against historical data and tells them if the plan will succeed or fail before they spend time and money executing it.

🔮 The AI Predicts
When you type a new CAPA plan into the system, it instantly tells you three things:
1. Will it work? (🟢 Effective vs 🔴 Ineffective / Needs Rework)
2. Will the mistake happen again? (⚠️ High Risk vs ✅ Low Risk of the problem returning within 90 days).
3. How long will it take? It predicts the exact number of days it will take to complete and close out the plan.
